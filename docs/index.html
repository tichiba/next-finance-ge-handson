3. シナリオ2：【GE + GWS横断検索】大口取引先の状況把握と社内規程の確認

timer 所要時間：12分

大口取引先（東都ロジスティクス株式会社）から「支払期日を翌月末（30日）から翌々月末（60日）へ延長してほしい」という特例相談が発生したシチュエーションです。
従来は営業・審査・法務の各ツールを個別に探していた「① 営業からの相談メール（Gmail）」「② 審査部内の議論履歴（Google Chat）」「③ 債権管理・与信規程PDF（Google ドライブ）」を、Gemini Enterprise のメインチャットから1回の質問で横断検索し、一覧表に構造化します。

gavel 【詳細版（任意）】該当条文（第11条・第14条・第18条）と車載IoT回線800回線増設可否まで明記させるプロンプト
大口契約先「東都ロジスティクス株式会社」からの支払期日延長（支払猶予）の相談に関して、営業部のメール報告、審査部・債権管理室のChat議論、および「通信料金等債権管理および与信運用規程」を横断検索し、以下の項目を一覧表に整理してください。 1. 対象取引先・契約回線数・月間請求額・今回の要請内容と過去の遅延経緯 2. 審査部・料金センターが懸念している法人他社（物流・建設セクター）および個人回線契約者（電話料金合算・払込票切替層）での類似傾向 3. 社内規程上の該当条文（第11条・第14条・第18条）、経営会議への付議基準、および必要な債権保全措置（新規車載IoT回線800回線の増設可否を含む）
📊 横断検索で自動的に抽出・整理される重要ファクト：
  • 対象取引先・経緯（メール）：東都ロジスティクス（契約4,850回線、月間請求額4,800万円、与信ランクC1）。過去6ヶ月（5月・8月）に2回の引落不能・遅延履歴あり。燃料高騰等を理由に30日→60日サイトへの延長を要請。
  • 現場の懸念点（Chat）：物流・建設セクターのランクC1/C2法人から同種のサイト延長相談が今月他に6社急増。個人回線でも払込票切替層の未収率が14.8%へ上昇。
  • 規程上の決裁基準（規程PDF）：第14条により「月間請求3,000万円以上」かつ「直近6ヶ月遅延2回以上」のため営業本部長決裁は不可、経営会議への付議・承認が必須。第18条により新規車載IoT回線800回線の増設は原則全面凍結、未使用与信枠20%圧縮＋債権保証（ファクタリング等）の付保が必要。

4. シナリオ3：【GE + AIエージェント】未収データ分析（請求×入金×与信）と経営会議レポート作成

timer 所要時間：18分

シナリオ2で「物流・建設セクターで同様の遅延相談が増えている」という現場の懸念が判明しました。
ここでは BigQuery Conversational Analytics データ分析エージェント（@請求・入金・与信分析） を呼び出し、SQLを1行も書かずに「① 請求データ」「② 入金・消込データ」「③ 顧客与信マスタ」を自然言語で掛け合わせて分析し、そのまま経営会議レポートとプレゼンスライドを1クリック出力します。

💡 エージェントの呼び出し方（2通り / スライド P.26〜28）：
  • 方法①（推奨・コピペ不要で文脈を引き継げる）：シナリオ2を実行した同じメインチャットの入力欄で半角の @ を入力し、候補から @請求・入金・与信分析 を選択してプロンプトを送信します。
  • 方法②（エージェント専用画面）：左メニューの「エージェント（Agents）」から 『請求・入金・与信分析』 を選択して対話することも可能です（※初回のみ「承認 / Authorize」ボタンをクリックしてアクセスを許可してください）。
