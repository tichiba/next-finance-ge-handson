3. シナリオ2：【GE + GWS横断検索】大口取引先の状況把握と社内規程の確認

timer 所要時間：12分

大口取引先の東都ロジスティクス株式会社から「支払期日を翌月末から翌々月末へ延長してほしい」という特例相談が発生したシチュエーションです。
従来は各ツールを個別に探していた「① 営業からの相談メール」「② 審査部内のチャット履歴」「③ 債権管理・与信規程PDF」を、Gemini Enterprise のメインチャットから1回の質問で横断検索し、一覧表に整理します。

manage_search Step 2-1：社内情報を一括検索して一覧表に整理

  1. 左メニューの 「新しいチャット」 をクリックしてメインチャット画面に戻ります。
  2. 以下のプロンプトをコピーし、チャット入力欄に貼り付けて送信します。
search メール・チャット・規程PDF 横断検索プロンプト
大口取引先である「東都ロジスティクス」からの支払期日延長の相談について、営業からの相談メール、審査部の同種相談急増に関するチャット議論、および「債権管理・与信規程PDF」を横断検索してください。その上で、以下の3点を一覧表に自動整理してください。 ① 対象取引先・対象金額・相談経緯 ② 審査部現場の懸念点 ③ 規程上の決裁条件（経営会議付議の基準・与信枠凍結ルール・該当条文）
gavel 詳細版：該当条文と車載IoT回線800回線増設可否まで明記させるプロンプト
大口契約先「東都ロジスティクス株式会社」からの支払期日延長の相談に関して、営業部のメール報告、審査部・債権管理室のチャット議論、および「通信料金等債権管理および与信運用規程」を横断検索し、以下の項目を一覧表に整理してください。 1. 対象取引先・契約回線数・月間請求額・今回の要請内容と過去の遅延経緯 2. 審査部・料金センターが懸念している法人他社および個人回線契約者での類似傾向 3. 社内規程上の該当条文（第11条・第14条・第18条）、経営会議への付議基準、および必要な債権保全措置（新規車載IoT回線800回線の増設可否を含む）
📊 横断検索で抽出・整理される重要ファクト：
  • 対象取引先・経緯：東都ロジスティクス（契約4,850回線、月間請求額4,800万円、与信ランクC1）。過去6ヶ月間に2回の引落不能・遅延履歴あり。燃料高騰等を理由に30日→60日サイトへの延長を要請。
  • 現場の懸念点：物流・建設セクターのランクC1/C2法人から同種のサイト延長相談が今月他に6社急増。個人回線でも払込票切替層の未収率が14.8%へ上昇。
  • 規程上の決裁基準：第14条により「月間請求3,000万円以上」かつ「直近6ヶ月遅延2回以上」のため営業本部長決裁は不可、経営会議への付議・承認が必須。第18条により新規車載IoT回線800回線の増設は原則全面凍結、未使用与信枠20%圧縮＋債権保証の付保が必要。

4. シナリオ3：【GE + AIエージェント】未収データ分析と経営会議レポート作成

timer 所要時間：18分

シナリオ2で「物流・建設セクターで同様の遅延相談が増えている」という現場の懸念が判明しました。
ここでは データ分析エージェント（@請求・入金・与信分析） を呼び出し、SQLを1行も書かずに「① 請求データ」「② 入金・消込データ」「③ 顧客与信マスタ」を自然言語で掛け合わせて分析し、そのまま経営会議レポートとプレゼンスライドを出力します。

💡 エージェントの呼び出し方：
シナリオ2を実行した同じメインチャットの入力欄で半角の @ を入力し、候補から @請求・入金・与信分析 を選択してプロンプトを送信します（左メニューの「エージェント」から選択して対話することも可能です）。

show_chart Step 3-1：全体傾向の把握

まずは全社の月次請求・入金・回収率の推移と、どの業種・与信ランクに未収リスクが集中しているかを可視化します。

insights 全体傾向の把握プロンプト
@請求・入金・与信分析 「請求・入金・顧客与信」のデータを掛け合わせ、以下を可視化してください。 (1) 2026年4月〜9月の月次請求額・入金済額・未収残高・回収率の推移（折れ線グラフ） (2) 未収リスクが拡大している「業種×与信ランク」別の未収残高・遅延傾向（棒グラフと表）
analytics エージェント個別画面用（@メンションなし）
2026年4月〜9月の月次請求総額・入金済額・未収残高・回収率の推移を集計し、折れ線グラフで可視化してください。あわせて、契約区分および業種/セグメント別・与信ランク別に6ヶ月累計の「請求総額」「現在の未収残高と未収率」を集計し、どのセグメントにリスクが集中しているか教えてください。

bar_chart Step 3-2：明細レベルへの対話ドリルダウンと債権保全シミュレーション

回収率が4月の 98.80% から9月に 93.80% へ低下し、物流・建設セクターの要注意層（C1/C2）に未収が集中していることが分かりました。続けて同じスレッドで、要注意の大口取引先トップ10社の抽出と与信枠見直し・保全措置によるリスク低減シミュレーションを行います。

leaderboard 明細ドリルダウン＆対策効果シミュレーション
@請求・入金・与信分析 続けて明細レベルへ深掘り分析してください。 (1) 未収・遅延の主要因である要注意の大口取引先トップ10社（業種・ランク・未収額・遅延日数）を棒グラフと表で表示 (2) 高リスク先の与信枠見直しと口座振替への切替による未収リスク低減効果をシミュレーション
calculate 詳細版：与信枠20%圧縮＋債権保証60%カバーを試算させるプロンプト
法人_多回線一括請求の要注意顧客（ランクC1・C2）について、累積未収残高が多いトップ10社を抽出して棒グラフで比較してください。 さらに社内規程（第14条・第18条）に基づき、各社の与信限度額を20%圧縮した場合の新与信枠と、未収残高の60%を債権保証で保全カバーした場合のリスク低減額および残余リスク額を試算してください。

groups 応用体験 ②：👥 人事・タレント分析（@人事・タレント分析）
